## Overview

A practical collection of scripts, command-line workflows, and repeatable techniques used to reduce repetitive work during security labs and testing.

## Focus

- Request generation and transformation
- Reconnaissance helpers
- Evidence collection
- Parsing and filtering tool output
- Reproducible testing workflows
- Linux-based security tooling

## Engineering principle

Automation should make testing more consistent, not replace understanding. Each script is built around a clearly defined task and is tested against authorized lab environments.
