## Overview

Security testing benefits from strong application-testing fundamentals. This project area connects functional testing with security thinking: understanding expected behaviour, identifying unexpected states, and validating how the application handles edge cases.

## Focus

- Functional versus security-relevant behaviour
- Input and state validation
- Error and response analysis
- Regression-minded security testing
- Clear defect and vulnerability reporting

This builds on my application testing experience and supports a security-first approach to software quality.
